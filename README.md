# Бомжемон

Покемоны, только ты бомж, а вместо покебола - картонная коробка.

    pip install -r requirements.txt
    python main.py

Управление: стрелки/WASD, Z/Enter/Space - ок, X/Esc/Backspace - назад.

## Управление
Стрелки/WASD - ходить, Z/Enter/Space - действие, X/Esc/Backspace - назад (на карте открывает меню).
F11 или Alt+Enter - полный экран, F10 - режим масштаба (целый множитель с полями / во весь экран).

## Консоль отладки
Открыть: ` (тильда, на русской раскладке клавиша Ё) или F1. Закрыть: то же или Esc. В бою не открывается.
Tab дополняет команды и id (вид, предмет, приём), стрелки вверх/вниз - история, PageUp/PageDown - прокрутка.
Номера существ - как в `party` (с 1). Виды можно писать по id или по русскому имени: `give крыса 10`.

    help [cmd]                    справка
    give <вид> [ур=5] [шт=1]      выдать существо (команда, а если полна - заначка);  giveall [ур] - по одному каждого вида
    party / storage / info <n>    список команды, заначки, подробности (опыт, статы, приёмы)
    level <n> <ур> [keep]         поставить уровень (приёмы пересоберутся);  exp <n> <кол-во> - начислить опыт как после боя
    evolve <n> [вид]              эволюция (без вида - первая возможная, с видом - принудительно)
    checkevo                      прогнать проверку эволюций по уровню у команды
    useitem <n> <предмет>         применить предмет эволюции/лечения, как в сумке
    item <предмет> [шт]  bag      выдать предмет / показать сумку
    teach <n> <приём> [ячейка]    научить приёму (если 4 - уйдёт в очередь выучки)
    hp <n> <зн>  status <n> <psn|brn|par|slp|none>  heal    HP, статус, лечение
    store <n> / take <n>          команда <-> заначка
    battle <вид> [ур]             дикий бой с выбранным существом;  trainer <id> - бой с тренером/лидером
    tp <x> <y>  tp                телепорт по карте / показать позицию
    money <n>  badge <id>  dex all|clear  list <species|items|moves|trainers|types>  save  clear  close

## Тесты (без pygame)

    python -m tests.smoke_ui          # прогон сцен и прогулок по карте на заглушке pygame

    python -m tools.balance_report    # нормированный турнир + лестница стадий (после правок статов)

## Куда класть файлы
    data/*.json                          весь контент: существа, приёмы, типы, предметы, тренеры, крафт, районы
    assets/sprites/creatures/<id>.png    спрайт существа (id = ключ в species.json, напр. rat.png). Рекомендуем 96x96, прозрачный фон
    assets/sprites/creatures/<id>_back.png  со спины (необязательно, иначе зеркалится передний)
    assets/tiles/*.png                   тайлсеты для карты (тайл 32x32)
    assets/fonts/*.ttf                   шрифт игры (берётся первый по алфавиту; нужна кириллица)
    assets/audio/                        музыка и звуки (подключим позже)
    maps/dump.tmj                        карта района из Tiled (JSON)
    saves/                               сохранения (создаются сами)

## Структура кода
    game/core/     окно, полный экран, стек сцен, загрузка данных
    game/battle/   Creature и движок боя (без pygame, возвращает события)
    game/world/    загрузчик карты Tiled (без pygame)
    game/systems/  эволюции, крафт, состояние игрока, сохранения
    game/ui/       виджеты и спрайты
    game/scenes/   title, world (карта + меню паузы), battle_scene, screens (команда/сумка/декс/крафт), debug_hub
    tools/ tests/  отчёты по балансу, генератор карты, тесты
    prototype_v0/  первый быстрый прототип (для истории)

## Состав
44 существа из таблицы «Бомжекимон» (data/species.json, id латиницей по названию - список в assets/sprites/creatures/NAMES.txt).
Стартовые: Хомеченнок, Щенок, Котёнок. Легендарные (не выпадают в траве): Голубиный король, Бингус, Белочка.
Эволюции: по уровню, по предмету (шприц, консервная банка, апарыши, крышка бака, прикормка, молочко, пальто),
по обмену и крафтом (5 крыс -> Крысиный король).
Обмен: «обмен на X» значит, что существо эволюционирует, когда его получают ВЗАМЕН существа X (Птенец <-> Крыса: оба эволюционируют).
На карте стоит NPC-Меняла: отдаёшь существо - получаешь то, что за него положено, сразу эволюционировавшим. В консоли: trade <n> [получить].
tools/build_roster.py - одноразовый генератор species.json (перезапишет правки!).

## Как добавлять контент
- Существо: запись в `data/species.json` + спрайт `assets/sprites/creatures/<id>.png`.
- Приём: `data/moves.json` (эффекты: status / confuse / flinch / stat). Эволюция: поле `evolutions` (level | item). Крафт: `data/fusions.json`.
- Тренер/лидер: `data/trainers.json`, на карте - объект типа trainer/leader с `trainer_id`.
- Карта в Tiled: слой `ground`, группа объектов `objects` (player_start, barrel, dumpster, item_spot, trainer, leader),
  свойства тайлов `solid` и `encounter`. Tile Layer Format = CSV. Подробности в game/world/mapdata.py.
